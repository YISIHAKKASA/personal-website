YISHAK KASA - PERSONAL WEBSITE MINI PROJECT

Files:
- index.html: website content and structure
- style.css: colors, layout, typography, hover effects, and responsive rules
- yishak-photo.png: your profile photo used in the hero section

How to run:
1. Extract the ZIP file.
2. Keep all three files in the same folder.
3. Open index.html in a web browser.
4. Edit the content in index.html and styling in style.css as needed.

Important:
- This project uses HTML and CSS only, as requested.
- The email button uses a placeholder address (your-email@example.com). Replace it with your real public contact email before presenting.
- Project cards are examples/concepts. Update them to accurately describe your own progress.
